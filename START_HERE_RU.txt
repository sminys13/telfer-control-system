V6 STEP9I — HE200 SERVICE COCKPIT
================================

ЭТО ОБЪЕДИНЁННЫЙ ПУСКОНАЛАДОЧНЫЙ ШАГ.
Он позволяет не перепрошивать Mega после каждой маленькой проверки.
После PASS текущих ворот можно сразу переходить к следующему этапу через браузер.

1. ДОМА / ПЕРЕД ОБЪЕКТОМ
-------------------------
Запустите:
  BUILD_STEP9I.bat

Обязательно получить:
  ALL STEP9I BUILDS: SUCCESS

2. ПЕРВАЯ ПРОВЕРКА БЕЗ ЗАПИСИ
-----------------------------
При необходимости загрузите:
  UPLOAD_STEP9I_READONLY.bat

Эта сборка только читает HE200.

3. ПУСКОНАЛАДОЧНАЯ СБОРКА
-------------------------
Только при реально подключённой и проверенной NC-цепи E-STOP:
  UPLOAD_STEP9I_FIELD_SERVICE.bat

Скрипт потребует вручную ввести FIELD.
AUTO/HOME всё равно останутся заблокированы.

4. СЕРВИСНОЕ ПРИЛОЖЕНИЕ
-----------------------
Запустите:
  OPEN_SERVICE_CONSOLE.bat

Chrome/Edge -> Подключить COM.

Нажмите «Подготовить систему».
Должно стать зелёным:
  PRE-FLIGHT = PASS

Нажмите «Проверить все 4».
Должно стать:
  Протокол HE200 = 4/4

ТОЛЬКО ПОСЛЕ ЭТОГО:
  на H1/H2/V1/V2 установить P0.02=2, P0.03=9
  и поставить галочку подтверждения в Service Cockpit.

Далее выполнить по интерфейсу:
  - H1 + / - и подтвердить направления;
  - H2 + / -;
  - V1 + / -;
  - V2 + / -;
  - парный H вправо/влево;
  - парный Z вверх/вниз.

После зелёных ворот становятся доступны контролируемые парные движения
с замедлением/восстановлением по возрасту лазерных данных.

5. ЛАЗЕРЫ
---------
Рабочий профиль зафиксирован:
  continuous / 5 Гц / 1 мм / 10 м

Лишние режимы 10/20 Гц, 0.1 мм и alternating single-shot из браузера удалены.

6. ПРОГРАММЫ
------------
Вкладка «Программа» — резервный сервисный редактор.
Она уже умеет работать с теми же слотами EEPROM, HOME/TRAVEL и зонами,
что использует DWIN/AutoRunner.
На Step9I физический AUTO не включается.

7. ГЛАВНОЕ ПРАВИЛО
------------------
Если теряется X1 ИЛИ X2 — замедляются H1 И H2 вместе.
Если теряется Z1 ИЛИ Z2 при парном вертикальном ходе — замедляются V1 И V2 вместе.
Никогда не оставляем второй привод пары ехать с полной скоростью.
