# V6 SYSTEM STEP9D — HMI, безопасный редактор и подготовка RS485

Версия прошивки: `v6-system-step9d-hmi-commissioning`

Эта версия продолжает проверенную Step9C и предназначена для окончательной привязки DWIN перед полевым пуском.

## Что изменено относительно Step9C

1. Выбор программы 1..4 теперь **не загружает** её автоматически.
   - `0x0314..0x0317` — только выбрать карточку/слот.
   - `0x0310` — загрузить выбранный слот.
   - `0x0311` — сохранить именно загруженный слот.
   - если выбранный и загруженный слоты различаются, SAVE отклоняется: сначала нажмите `Загрузить`.

2. Ручной ввод координат стал безопаснее.
   - изменение X1 или X2 снимает признак валидности пары X;
   - изменение Z1 или Z2 снимает признак валидности пары Z;
   - кнопка `Принять` подтверждает пару только если после загрузки/смены зоны оператор реально ввёл **оба** значения пары;
   - просто нажать `Принять` на нулевых полях больше нельзя.

3. Наклон теперь трактуется именно как **разница координат Z1 и Z2 в миллиметрах**.
   - VP остаётся `0x1310`;
   - значение N означает требуемый перепад `|Z1-Z2| = N мм`;
   - поле на экране лучше подписать `Перепад Z1-Z2, мм` или `Наклон слива, мм`.

4. Добавлен режим `hold-to-run` для ручных стрелок.
   - новый VP `0x1110`;
   - стрелки рекомендуется сделать в DGUS как **Bit Button**, режим **Inching**;
   - нажатие = бит 1 = движение;
   - отпускание = бит 0 = немедленный ручной STOP;
   - старые команды `0x0101..0x010C` и `0x010F` сохранены.

5. RS485/VFD редактор из предыдущих шагов сохранён и готов к привязке числовых полей DWIN.

# 1. Как сделать числовой ввод в DGUS

Для каждого редактируемого поля нужны два объекта на одном месте:

- **Data Variable** (или ваш существующий объект отображения значения) — показывает текущее значение VP;
- **Touch Variable -> Variable Data Input** — прозрачная/невидимая область поверх числа, по нажатию открывает цифровую клавиатуру и записывает результат в тот же VP.

Для Step9D используйте:

- `V_Type = 0x00` — 2-byte integer / unsigned integer;
- `N_Dot = 0` — без десятичной части;
- число целых разрядов (`N_Int`) выбирайте по диапазону поля;
- по возможности включите ограничение Min/Max.

Все редактируемые поля Step9D сейчас целочисленные.

## Минимальный тест ввода

Для проверки удобнее всего первым сделать поле `Выдержка в ванне`:

- VP: `0x130E`
- диапазон: `0..36000`
- десятичных знаков: `0`

Нажмите поле, введите, например, `15`, нажмите OK. В терминале после успешной автоотправки DWIN значение попадёт в редактор программы.

# 2. Ручное управление: нажал — едем, отпустил — стоп

Рекомендуемая Step9D настройка каждой стрелки:

- Touch Control: **Bit Button**
- VP: `0x1110`
- Adjustment mode: **Inching** (`press=1`, `release=0`)
- у каждой стрелки свой `Bit position`.

| Бит VP 0x1110 | Действие |
|---:|---|
| 0 | H1 вперёд / X1 + |
| 1 | H1 назад / X1 - |
| 2 | H2 вперёд / X2 + |
| 3 | H2 назад / X2 - |
| 4 | H1+H2 вперёд |
| 5 | H1+H2 назад |
| 6 | V1 вверх / Z1 + |
| 7 | V1 вниз / Z1 - |
| 8 | V2 вверх / Z2 + |
| 9 | V2 вниз / Z2 - |
| 10 | V1+V2 вверх |
| 11 | V1+V2 вниз |

При отпускании любой стрелки VP возвращается к 0, а прошивка выполняет ручной STOP. Сторожевой таймер остаётся вторым уровнем защиты.

Если пока не хотите переделывать кнопки, старые Return Key Code продолжают работать:

- `0x0101..0x010C` — движения;
- `0x010F` — ручной JOG STOP.

# 3. Нижнее меню и HOME

Не путать навигацию и команды механизма.

| Экранная кнопка | Настройка |
|---|---|
| Главная | только Page Switch, команды Arduino нет |
| Ручной | Page Switch + `VP 0x1100 = 0x0001` |
| Авто в нижнем меню | только Page Switch |
| Программы | только Page Switch |
| Калибровка | Page Switch + `0x0006` |
| Настройки | Page Switch + `0x0005` |
| СТОП | `0x0004` |
| Домой / HOME | `0x0003` — это движение механизма, не переход на Главную |

На странице AUTO:

- Старт `0x0002`
- Пауза `0x0300`
- Продолжить `0x0301`
- Следующий/подтвердить `0x0302`
- Симуляция `0x0303`

# 4. Программы

## Карточки программ

Все пишут в `VP 0x1100`:

- Программа 1: `0x0314`
- Программа 2: `0x0315`
- Программа 3: `0x0316`
- Программа 4: `0x0317`

В Step9D это только **выбор** карточки. После выбора нажмите:

- `Загрузить` = `0x0310`

Только после LOAD программа становится активной/редактируемой.

- `Сохранить` = `0x0311`
- `По умолчанию` = `0x0312`
- зона назад = `0x0318`
- зона вперёд = `0x0319`
- зона ВКЛ/ВЫКЛ = `0x031A`

`Редактор 1` и `Редактор 2` — только Page Switch, контроллерной команды для перехода не требуется.

## Кнопки координат

- снять HOME X1/X2 с датчиков: `0x0320`
- снять TRAVEL Z1/Z2: `0x0321`
- снять X1/X2 текущей зоны: `0x0322`
- снять Z1/Z2 текущей зоны: `0x0323`
- снять Dry X1/X2: `0x0324`
- снять Dry Z1/Z2: `0x0325`

Ручное подтверждение числового ввода:

- принять X1/X2 зоны: `0x0326`
- принять Z1/Z2 зоны: `0x0327`
- принять HOME X1/X2: `0x0328`
- принять TRAVEL Z1/Z2: `0x0329`
- принять Dry X1/X2: `0x032A`
- принять Dry Z1/Z2: `0x032B`

**Step9D требует фактический ввод обоих чисел пары перед `Принять`.**

# 7. RS485 / частотники

Команды сервисного экрана (`VP 0x1100`):

- применить в RAM: `0x0200`
- применить и сохранить EEPROM: `0x0201`
- загрузить EEPROM: `0x0202`
- безопасные значения по умолчанию: `0x0203`
- тест H1: `0x0204`
- тест H2: `0x0205`
- тест V1: `0x0206`
- тест V2: `0x0207`
- тест всех: `0x0208`

Числовые VP:

| Параметр | VP | Значение |
|---|---:|---|
| Baud code | `0x1200` | 0=4800, 1=9600, 2=19200, 3=38400, 4=57600, 5=115200 |
| Чётность | `0x1202` | 0=None, 1=Even, 2=Odd |
| Stop bits | `0x1204` | 1 или 2 |
| Timeout ответа, мс | `0x1206` | по умолчанию 150 |
| Повторы | `0x1208` | 0..5 |
| Интервал запросов, мс | `0x120A` | по умолчанию 10 |
| Online poll, мс | `0x120C` | период опроса online |
| Offline poll, мс | `0x120E` | период повторной проверки offline |
| Адрес H1 | `0x1210` | Modbus ID |
| Адрес H2 | `0x1212` | Modbus ID |
| Адрес V1 | `0x1214` | Modbus ID |
| Адрес V2 | `0x1216` | Modbus ID |
| Инверсия направлений | `0x1218` | битовая маска H1/H2/V1/V2 |
| JOG watchdog, мс | `0x1220` | по умолчанию 2500 |
| E-STOP monitor | `0x1222` | 0/1, отключение только BENCH |
| LIMIT monitor | `0x1224` | 0/1 |

Профили приводов:

- H1 base `0x1230`
- H2 base `0x1240`
- V1 base `0x1250`
- V2 base `0x1260`

Смещения от base:

- `+0x00` ручная скорость, %
- `+0x02` максимальная скорость, %
- `+0x04` медленная скорость, %
- `+0x06` расстояние начала замедления, мм
- `+0x08` допуск остановки, мм

Для первой полевой проверки лучше оставить текущие `9600 / Even / 1 stop bit`, адреса `1/2/3/4`, затем проверить каждый ПЧ в READ-ONLY среде.

# 9. Рекомендуемая последовательность проверки Step9D

На столе использовать среду:

`mega_v6_sensor_core_fast`

1. Проверить загрузку Step9D.
2. Проверить выбор программы: P2 -> должно быть `selected=2`, но loaded остаётся прежним.
3. Нажать LOAD -> P2 становится loaded.
4. В Редакторе 2 настроить Variable Data Input на `0x130E`, ввести `15`.
5. Проверить защиту пары: нажать `Принять X` без ввода X1 и X2 -> должно быть `rejected: enter BOTH values first`.
6. Настроить одну стрелку H1 как Bit Button/Inching VP `0x1110`, bit0. При удержании должен появиться H1_FWD, при отпускании — `DWIN jog release` и STOP.
7. После успешной проверки перенести остальные 11 стрелок на биты 1..11.

Полевой порядок остаётся:

1. `mega_v6_ne200_readonly` — только связь с реальными ПЧ.
2. `mega_v6_ne200_field_manual` — реальные ручные движения, AUTO/HOME запрещены.
3. Только после проверки направлений, торможения, датчиков и безопасности — `mega_v6_ne200_field_auto`.
