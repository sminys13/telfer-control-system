# V6 Continuous 10 Hz No-Autorestart

Экспериментальная версия после полевых испытаний.

Изменение: в `fast_laser_sensor.cpp` отключён автоматический рестарт continuous-режима при потере свежих кадров.

Почему: при ускорении объекта датчик временно терял валидные кадры, прошивка считала канал устаревшим и снова отправляла `LASER ON -> RANGE -> RESOLUTION -> FREQ -> CONTINUOUS`. Визуально это выглядело как постоянное мигание датчика, а измерения ухудшались даже после замедления.

Теперь в режиме Running прошивка только слушает входящий поток и парсит валидные кадры. Если данные временно пропали, последнее валидное значение остаётся на DWIN, а ошибка показывается через `ERROR`. Автоматического моргания/рестарта нет.

Режим датчика:

```text
LASER ON
SET RANGE 10m
SET RESOLUTION 1mm
SET FREQUENCY 10Hz
CONTINUOUS
```

Ожидание: если залипания были вызваны именно автоперезапуском канала, после этой версии датчик перестанет постоянно мигать после ускорения. Если данные всё равно пропадают, но без мигания, значит ограничение уже в самом измерительном режиме/цели, и следующим шагом надо пробовать continuous + read cache без рестарта или 5 Hz.
