## Исправления в итоговом патче

Унаследованные исправления Step9J проверены повторно: карточка и кнопка импульса имеют разные атрибуты, обработчик установлен только на кнопках; один click вызывает один обработчик. Некорректная команда `undefined` отклоняется. Ручные подтверждения больше не калибруют направление. Знак определяется по свежим стабильным сырым лазерным расстояниям до/после двух противоположных физических команд, при подтверждённом электрическом RUN/STOP. В симуляции FWD −20 мм / REV +20 мм даёт **«+» → REV**, **«−» → FWD**. Физическая повторная калибровка H1/H2 ещё не проводилась.

Парные тесты не получают разрешение от старых галочек. В диагностической поставке дополнительно постоянно заблокировано всякое физическое движение, включая калибровочные импульсы, пары, Assisted, AUTO/HOME. Здесь нет команды снятия этой блокировки. Программный STOP также не отправляется: остановка установки должна обеспечиваться аппаратно.

Дополнительно исправлено в этой сессии:

- Повторный `service info` той же прошивки сохраняет текущий опрос; загрузочная строка `FW:` очищает прошлую сессию.
- Старая отмена другого scan не прерывает новый снимок; несовместимый START отклоняется.
- Для каждого привода адрес остаётся постоянным; разные приводы не могут незаметно использовать один адрес. Это не заменяет физическую идентификацию адресов H1/H2/V1/V2.
- Противоречивые повторные строки и несовпадение счётчика ошибок делают снимок недостоверным. Недопустимая строка не заменяется нулём или новым значением.
- Ошибки чтения остаются «НЕИЗВЕСТНО». Наличие всех ответов означает завершённый опрос, а не успешное чтение всех параметров.
- Заблокированные кнопки STOP не становятся доступными из-за заявления подключённой прошивки о снятом lock. Интерфейс не поддерживает движение.
- Убран вывод о причине прежнего отказа из прямого сравнения raw-значений частоты в текущем неподвижном снимке.
- В Modbus явно проверяется минимальная длина ответа до CRC; счётчик повторов не переполняется при 255. Рабочая настройка остаётся прежней.

## Следующий согласуемый шаг

Сначала установить, что сейчас прошито в Mega. Для старой FIELD SERVICE открытие порта может привести к перезагрузке и обработке E-STOP с отправкой STOP по старому коду. Разрешение только чтения не считается разрешением этой записи.

После отдельного подтверждения оператора о безопасном неподвижном состоянии и независимой аппаратной защите согласовать при необходимости загрузку диагностической READ-ONLY. Затем получить `service info` с `diagnosticLock=1` и выполнить единственный общий опрос `he200 audit all` — 372 FC03, без RUN/STOP/FC06. До согласования COM8 не открывать. Если установка недоступна, оператор может вручную записать указанные параметры и состояния панели всех четырёх ПЧ без их изменения.
