## Доказанный результат

Это не доказательство неисправности двигателя или тормоза и не доказательство конкретного активного входа.

## Руководства и назначения входов

Проверены страницы английского руководства из предоставленного `sources/HE200_manual.zip` (сканы страниц 12–15) и HE200 A6 V3.2 на китайском (страницы 11–14, 17, 21, 34–35, 41–42 и Appendix A 48–50).

Китайский PDF: https://31729621.s21i.faiusr.com/61/ABUIABA9GAAg7effvQYopuqWlgQ.pdf
Страница поставщика, размещающего файл под именем HE200说明书A6_V3.2.pdf: https://www.lvweisifu.com/

Это руководство именно HE200, а не карта Goodrive/NE200. Файл размещён поставщиком, не подтверждён производителем для конкретной аппаратной ревизии пользователя. Английская версия описывает четыре клеммы X1–X4, китайская также X5/X6; различие учтено как возможная несовместимость отдельных читаемых адресов. Назначения первых четырёх входов и P4.38 совпадают в обеих версиях.

| Подтверждённая пользователем настройка всех ПЧ | Значение по HE200 |
|---|---|
| P0.02=2 | Источник команд: связь |
| P0.03=9 | Основной источник частоты: связь |
| P0.27=0 | Привязка источников отсутствует |
| P4.00=1 | X1: FWD |
| P4.01=2 | X2: REV |
| P4.02=10 | X3: пауза RUN |
| P4.03=9 | X4: сброс ошибки |
| P4.11=0 | Двухпроводный режим 1 |

Таким образом, прежнее предположение, что P4.03=9 может означать внешний STOP, неверно. P4.38 задаёт активный уровень входов, а P4.35–P4.37 — задержки. Назначенная функция и её фактическая активность — разные данные.

У документа нет достаточной для этого кода проверенной побитовой расшифровки 0x4030, визуальных слов 0x7029–0x702C и 0x703D. Нельзя объявить X3 активным или неактивным, просто трактуя младшие биты произвольным образом. Патч сохраняет raw-значения, в том числе альтернативное слово входов 0x1008, для сопоставления с панелью и ревизией.

Appendix A задаёт чтение параметров P-группы по Fxxx: P0.27 → F01B, P4.11 → F40B, P4.38 → F426. Адреса 0xxx являются альтернативами для записи RAM и не используются для чтения. 2000H — команда; 0005 — выбег, 0006 — замедленный останов. 2001H относится к управлению выходами, не к частоте. Диагностический патч не пишет ни в один из этих адресов.

## Какие объяснения пока остаются непроверенными

Неизвестны фактическая полярность/состояние X3, виртуальные входы, источник/режим после переключений, нижняя частота и действие ниже неё, режим и выдержки пуска, режим момента и версии прошивок ПЧ. Любая из этих проверок — сбор данных, а не установленная причина.

P6.04/P6.06 и стартовая логика важны потому, что окно RUN в старом тесте только 1200 мс. Преждевременное увеличение длительности или частоты без выяснения настроек не предлагается. Нулевое напряжение ПЧ само по себе не устанавливает состояние механического тормоза. Совпадение DI у H и V делает объяснение «точно один и тот же стоп-вход» недоказанным.

## Исправления

1. Причина `undefined` воспроизведена: `data-pulse-drive` стоял на карточке и кнопках; обработчики навешивались на оба элемента. Всплытие click давало второй вызов без `data-dir`. Карточка теперь имеет отдельный атрибут, обработчик назначается только кнопкам. Параметры команды проверяются; повторный импульс не ставится в очередь, пока первый не завершён. В диагностическом UI команды движения вообще запрещены.
2. Ручное `service confirm` больше не создаёт калибровку. Отдельный алгоритм использует свежие стабильные raw-координаты, два противоположных направления, подтверждение электрического RUN/STOP и отсутствие смещения других каналов. Исторические галочки сбрасываются. Для H1/H2 наблюдение пользователя FWD → уменьшение расстояния согласуется с новым правилом «+ → REV», но физическая повторная калибровка ещё не проведена.
3. Все 93 адреса читаются на всех четырёх приводах, по одному слову FC03 за шаг. Процедура не пишет настройки, уставки, STOP/RESET, не обходит неизвестные регистры записью и не открывает движение. Она не является атомарным снимком: метка времени каждого ответа сохраняется.
4. Неподдерживаемый адрес, CRC, таймаут, неправильный адрес/функция ответа и неполные данные остаются явными ошибками. Короткий Modbus exception из пяти байтов распознаётся как exception; код исключения не теряется.
5. Общий запрет физических FC06 действует и при использовании старого интерфейса с новой прошивкой. Новому интерфейсу необходима новая прошивка для audit. Работа PRE-FLIGHT и прежних маршрутов AUTO не считается независимой защитой.

## Граница проверки

Сборка и тесты проверяют программное поведение, не реальную установку. Фактический диагноз V1/V2, применимость каждого адреса к ревизии, работоспособность E-STOP/концевиков/тормозов и физические знаки после обновления ещё не подтверждены. До получения нового журнала и проверки аппаратной части разблокирование движения не подготовлено.
