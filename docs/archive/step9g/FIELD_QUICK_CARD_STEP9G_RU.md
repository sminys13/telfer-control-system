# Step9G — краткая карточка

## Запуск

```text
BUILD_STEP9G.bat
UPLOAD_STEP9G_WAVESHARE_READONLY.bat
OPEN_SERVICE_CONSOLE.bat
```

В приложении:

```text
Каналы: X1 + X2
База: 5 Гц / выходное разрешение 1 мм
```

## Мишень

```text
жёсткая плоская матовая белая поверхность
ПВХ 3–5 мм или матово окрашенный металл
200×200 мм или больше
около 90° к лучу
чистая и сухая
```

## Видимая точка

Короткое регулярное мерцание возможно: видимый лазер выключается после измерения. При длинной тёмной паузе нажать метку X1/X2. Решение принимать по логу, а не только глазами.

## Тесты

```text
1. статика 5 Гц / 1 мм / 120 с
2. та же статика 5 Гц / 0,1 мм / 120 с
3. движение continuous 5 Гц / 1 мм
4. alternating X1/X2 5 Гц / 1 мм
5. при таймаутах — alternating 2 Гц / 1 мм
6. если X2 хуже — поменять физические X1/X2 местами
```

## В конце

```text
laser alternate stop
laser status
```

Ожидается:

```text
X1/X2: mode=cont res=1 freq=5 ack=0x3F missing=0 nack=0
```

## Не выполнять

- AUTO/HOME;
- запись в HE200;
- изменение `P0.02`;
- использование 20 Гц как рабочего режима.
