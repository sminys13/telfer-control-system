# Step9F — краткая карточка на объект

## Прошивка

```text
mega_v6_he200_waveshare_readonly
```

## Сервисное приложение

```text
tools\telfer_service_console\start_console.bat
```

Перед подключением закрыть PlatformIO Monitor.

## Один HE200

1. `120R OFF`, `SGND` свободен, pin 6 свободен.
2. Подключить COM в приложении.
3. `Тихий журнал`.
4. `Профиль 9600 8N1`.
5. `H1`.
6. Успех: `@HE200 ... online=1 ... error=0`.

## Четыре HE200

1. По очереди `H1`, `H2`, `V1`, `V2`.
2. Затем `Все ПЧ`.
3. Сохранить журнал.

## Лазеры

1. `Реинициализация`.
2. Подождать 5 с.
3. `Состояние`.
4. Норма: `ack=0x3F`, `missing=0`, `nack=0`, `crc=0`, `uart*=0`.

## Тест частоты

1. `Начать 5 Гц` → одинаковый маршрут → сохранить лог.
2. `Начать 10 Гц` → тот же маршрут → сохранить лог.
3. `Начать 20 Гц` → тот же маршрут → сохранить лог.
4. `Полевой отчёт` → сохранить общий лог.

Все движения — только физическим пультом. READ-ONLY приложение не должно передавать FC06.
