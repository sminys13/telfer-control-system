# Изменения Step9F относительно Step9E

## Лазеры

- исправлены команды диапазона, частоты и разрешения: добавлен обязательный байт `FA`;
- добавлена последовательность `shutdown → laser on → 10 m → 1 mm → frequency → continuous`;
- добавлена проверка ACK, missing ACK и NACK;
- добавлены режимы 5/10/20 Гц;
- добавлен разбор `ERR--xx`;
- добавлены счётчики checksum, malformed, range reject и discarded bytes;
- добавлено чтение ошибок UART SC16;
- добавлена фактическая частота кадров;
- предел остаётся 10 000 мм.

## HE200 / RS485

- добавлен отдельный профиль нового Waveshare с автоматическим переключением направления;
- pin 6/DE-RE в этом профиле не используется;
- HE200-профиль 9600 8N1 и адреса 1/2/3/4 автоматически применяются в RAM при старте commissioning-сборки;
- записи HE200 по-прежнему запрещены;
- добавлены структурированные строки `@HE200` для сервисного приложения.

## Сервис

- добавлена браузерная сервисная консоль без внешних Python-библиотек;
- кнопки диагностики вместо ручного набора команд;
- таблицы лазеров и HE200;
- автоматические сеансы 5/10/20 Гц;
- сохранение журнала;
- предупреждение, если обнаружен FC06 или сборка с разрешённым физическим AUTO.

## Проект

- удалён фиксированный COM-порт из `platformio.ini`;
- оставлены три поддерживаемые среды;
- CI переведён на matrix-build трёх сред;
- старая документация перенесена в `docs/archive/step-history`;
- корневой README и WIRING приведены к фактической конфигурации.
