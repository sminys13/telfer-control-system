Управление с удержанием

«+» увеличивает координату соответствующего лазера, «−» уменьшает. Отпускание кнопки останавливает движение. Парное управление доступно после проверки направлений обоих приводов.

HOME и транспортная высота задаются в программе.

Проверка знака по лазеру

Для каждого привода выполните FWD и REV. Пульт измерит изменение расстояния и сохранит знак после двух согласованных измерений. При перестановке проводов повторите проверку.
