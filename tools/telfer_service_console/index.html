Step9J · Диагностика четырёх HE200

Только чтение FC03. RUN, изменение настроек, сброс ошибок, парные движения и AUTO заблокированы в этой поставке.

Программный STOP здесь не действует. Для остановки оборудования нужна независимая аппаратная цепь.

Ожидание подключения Step9J

Неизвестное значение и ошибка чтения не считаются нормой. Состояния DI сохраняются как raw: кодирование битов требует проверки по панели.

Параметр / регистрH1 · 1H2 · 2V1 · 3V2 · 4Сопоставление

Калибровка знака сброшена. «+» всегда означает увеличение сырого лазерного расстояния. FWD/REV связываются со знаком только по измерениям двух направлений; подъём/спуск требуют отдельного подтверждения.

Результаты старых ворот Step9I не разрешают движение в диагностической поставке.

2. Подтверждение Modbus-карты

ПЧ должны стоять. Проверяется 1000H → 701CH и 2000H=0006 без команды RUN. Пробное значение ограничено 5%.

3. Переключение источника управления

Параметры только читаются и сравниваются с заявленными значениями. Изменения не предлагаются до разбора полного снимка.

4. Низкоскоростные импульсные тесты

Каждый тест автоматически даёт малую скорость, проверяет факт вращения и сам отправляет плавный STOP. Знак подтверждается только измерением двух противоположных направлений; тесты сейчас заблокированы.

6. Контролируемое движение с восстановлением датчиков

Если один датчик пары старше 650 мс — синхронно уменьшается скорость обоих ПЧ. После восстановления скорость плавно возвращается. После 1200 мс — дотормаживание до 0; после свежих кадров возможен автоматический мягкий рестарт. 5 с без данных = FAULT.
