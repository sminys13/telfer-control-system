# Step9I Service Cockpit

Браузерный сервисный интерфейс запускается `OPEN_SERVICE_CONSOLE.bat` и использует Web Serial Chrome/Edge.

## Вкладки

### Пусконаладка
Последовательные ворота:
PRE-FLIGHT -> Protocol 4/4 -> operator source confirmation -> Directions 8/8 -> Pair 2/2 -> Assisted motion.

### Датчики
Только рабочий профиль SEN0366: continuous, 5 Гц, 1 мм, 10 м. Экспериментальные режимы скрыты/убраны.

### Программа
Резервный редактор слотов EEPROM, HOME/TRAVEL и зон. Физический AUTO в Step9I не включается.

### Журнал
Полный поток COM + сохранение TXT. Произвольная консольная команда оставлена только под сворачиваемым «Сервисная команда вручную».

## Важное

До импульсных тестов HE200 требуется:

```text
P0.02 = 2
P0.03 = 9
```

но Service Cockpit намеренно не записывает эти параметры автоматически: оператор подтверждает их вручную после Protocol PASS.

Под воротами есть единый GO/NO-GO баннер: он показывает, выполнен ли текущий допуск и какой шаг разрешён следующим.

Верхняя красная кнопка STOP отправляет штатный HE200 deceleration stop (`2000H=0006`) на все четыре привода. Кнопка STOP внутри Assisted motion тормозит только активную пару. Ни одна из них не является аппаратным E-STOP.

## Исправление отображения PRE-FLIGHT
Эта версия интерфейса различает `ОЖИДАНИЕ`, `PASS` и `FAIL` и показывает причину из строки `@GATE name=PREFLIGHT ...`.

Для FIELD SERVICE вход E-STOP контроллера является fail-safe NC status input:
- Mega pin 2 LOW = нормальное состояние (NC контакт замкнут на GND)
- pin 2 HIGH/open = E-STOP ACTIVE
После отпускания E-STOP защёлка очищается командой `clear`.

Концевики H1L/H1R/H2L/H2R: pins 36/37/38/39. В FIELD NC нормальное состояние также LOW. Если концевики реализованы только аппаратно вне Mega, программный мониторинг можно отключить командой `limits off`; E-STOP в FIELD программно отключить нельзя.
