# V6 system step 1 — возврат функционала поверх нового датчикового ядра

База: `mega_v6_sensor_core_fast`.

Сохраняется рабочий датчиковый режим:

- RANGE 10m
- RESOLUTION 1mm
- FREQ 20Hz
- CONTINUOUS
- без READ_CACHE
- без AUTO_RESTART
- без SINGLE в движении
- координаты X1/X2/Z1/Z2 удерживают последнее валидное значение и не сбрасываются в 0
- ZERO/SAVE/LOAD/RESET остаются рабочими

## Новые команды DWIN VP_CMD = 0x1100

Все кнопки DWIN: Return Key Code, VP `1100`, Data auto-uploading ON.

| Команда | HEX | Назначение |
|---|---:|---|
| ZERO X1 | 0021 | Обнулить X1 по текущему свежему raw |
| ZERO X2 | 0022 | Обнулить X2 |
| ZERO Z1 | 0023 | Обнулить Z1 |
| ZERO Z2 | 0024 | Обнулить Z2 |
| SAVE | 0030 | Сохранить offsets/settings в EEPROM |
| LOAD | 0031 | Загрузить последнее сохранённое |
| RESET CAL | 0032 | Сбросить offsets в RAM |
| SERVICE | 0040 | Режим датчики/калибровка |
| STOP | 0041 | Безопасный стоп-режим, пока без управления приводами |
| MANUAL | 0042 | Ручной режим как состояние, приводы будут подключены следующим шагом |
| AUTO | 0043 | Авто режим как состояние, программа будет подключена после ручного режима |
| CLEAR STATUS | 0044 | Обновить статус ошибок |
| SENSOR REINIT | 0045 | Ручной перезапуск continuous-инициализации датчиков |

## VP_MODE

| Значение | Состояние |
|---:|---|
| 21 | SERVICE / датчики |
| 30 | STOP |
| 31 | MANUAL |
| 32 | AUTO |

## VP_ERROR

Биты `0..3` — LOST/no value:

- 1 = X1 LOST
- 2 = X2 LOST
- 4 = Z1 LOST
- 8 = Z2 LOST

Биты `4..7` — STALE, последнее значение удерживается:

- 16 = X1 STALE
- 32 = X2 STALE
- 64 = Z1 STALE
- 128 = Z2 STALE

## Важно

На этом шаге команды MANUAL/AUTO только переключают состояние. Команды движения частотникам специально ещё не отправляются. Следующий шаг — вернуть ручной режим через RS485/частотники с учётом FRESH/STALE/LOST.
