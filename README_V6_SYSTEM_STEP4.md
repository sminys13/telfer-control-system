# V6 System Step4 — Motor State для DWIN

Этот шаг не включает реальные выходы и не отправляет команды частотникам. Он добавляет устойчивое внутреннее состояние движения и выводит его на DWIN.

## Новое поле DWIN

Добавить на страницу ручного режима числовое поле:

```text
VP = 1014
Digits = 3..5
```

Это поле показывает `MOTOR_STATE`.

## Значения MOTOR_STATE

```text
0   IDLE
1   H1/X1 вперед
2   H1/X1 назад
3   H2/X2 вперед
4   H2/X2 назад
5   H1+H2 вперед
6   H1+H2 назад
7   V1/Z1 вверх
8   V1/Z1 вниз
9   V2/Z2 вверх
10  V2/Z2 вниз
11  V1+V2 вверх
12  V1+V2 вниз
20  STOPPED
30  BLOCKED
```

## Проверка

1. Нажать `0001 Manual` — `VP_MODE` станет `1`, `MOTOR_STATE` станет `0`.
2. Нажать `0101 H1/X1 вперед` — `MOTOR_STATE` станет `1`.
3. Нажать `0102 H1/X1 назад` — `MOTOR_STATE` станет `2`.
4. Нажать `010F Jog Stop` — `MOTOR_STATE` станет `20`.
5. Нажать ручную команду не в Manual — `MOTOR_STATE` станет `30 BLOCKED`.

## Важно

Физического управления пока нет. Это безопасный программный каркас для следующего шага — подключения VFD/RS485.
