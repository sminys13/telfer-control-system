# Telfer Control System — V6 Step9I Service Cockpit

Step9I объединяет несколько следующих этапов пусконаладки в одну управляемую последовательность. Основной сервисный интерфейс — браузерная Web Serial консоль; DWIN в этом шаге не нужен для движения и не участвует в разрешении физических команд.

## Что фиксируем

- Arduino Mega 2560;
- четыре SEN0366-протокольно совместимых лазера через два SC16IS752;
- профиль лазеров: **continuous, 5 Гц, 1 мм, 10 м**;
- четыре HE200, Modbus RTU 9600 8N1, адреса H1/H2/V1/V2 = 1/2/3/4;
- изолированный Waveshare TTL TO RS485 (B), automatic direction;
- нативная карта HE200: `1000H` communication setpoint, `2000H` control word, `3000H` status;
- `0006` — штатный deceleration stop; `0005` (free/coast stop) сервисным интерфейсом **не используется**;
- физические AUTO/HOME остаются compile-time **BLOCKED**.

## Три сборки

### `mega_v6_sensor_core_fast`
Безопасный стенд/dry-run.

### `mega_v6_he200_waveshare_readonly`
Физическое чтение HE200, все записи запрещены.

### `mega_v6_he200_field_service`
Отдельная пусконаладочная сборка. Разрешает только runtime-gated сервисные записи HE200 и контролируемое ручное движение из Service Cockpit. Требует FIELD/NC E-STOP. DWIN-команды движения выключены. Физический AUTO/HOME заблокирован.

## Ворота допуска

Service Cockpit не предлагает сразу нажать RUN. Допуск набирается последовательно:

1. **PRE-FLIGHT PASS** — E-STOP/limits допустимы, все четыре HE200 онлайн, без fault и стоят.
2. **PROTOCOL 4/4 PASS** — на каждом ПЧ подтверждены `1000H -> 701CH` и безопасная запись `2000H=0006` на уже стоящем приводе.
3. Оператор вручную переводит четыре HE200 в `P0.02=2`, `P0.03=9` и подтверждает это в браузере.
4. Низкоскоростной импульс каждого привода в `+/-`; прошивка подтверждает RUN + последующий STOP, оператор подтверждает физическое направление.
5. Парные импульсные тесты H1+H2 и V1+V2.
6. Только после этого доступны контролируемые парные перемещения с автоматическим замедлением при устаревании любого датчика пары.

`@GATE_STATE` — машиночитаемый маркер текущего допуска. После каждой проверки приложение обновляет зелёные/жёлтые ворота. Под ними показан единый баннер **СЛЕДУЮЩЕЕ ДЕЙСТВИЕ / GO-NO-GO**: при FAIL он явно запрещает переход дальше, при PASS подсказывает ровно следующий этап.

## Алгоритм восстановления датчиков

Для H1+H2 либо V1+V2 пара всегда рассматривается как единая кинематическая система.

- до 450 мс — NORMAL;
- 450…650 мс — WARNING;
- более 650 мс — DECEL сразу **обоих** ПЧ пары;
- более 1200 мс — продолжить плавное снижение **обоих приводов выбранной пары** до 0;
- более 5000 мс — FAULT;
- если данные возвращаются во время торможения — после 3 свежих парных кадров плавно вернуть скорость;
- после полной остановки — мягкий рестарт только после 5 свежих парных кадров.

Рамп: каждые 200 мс изменение setpoint на 5 процентных пунктов. Это сервисный алгоритм для проверки концепции, а не замена аппаратного E-STOP.

## Программы через браузер

Вкладка «Программа» является резервным редактором EEPROM-программ и использует существующие структуры V6. Можно:

- загрузить/сохранить слот 1…4;
- задать или снять HOME X1/X2;
- задать или снять TRAVEL Z1/Z2;
- задавать X1/X2/Z1/Z2 зоны;
- выдержку, паузу после наклона, перепад Z1-Z2 в мм;
- скорости H/V;
- включать/выключать зону.

Физический AUTO на Step9I всё равно не запускается. Это сознательно: сначала подтверждаем Modbus и контролируемое ручное движение.

## Быстрый старт

```text
BUILD_STEP9I.bat
UPLOAD_STEP9I_READONLY.bat       (если нужен только контроль)
UPLOAD_STEP9I_FIELD_SERVICE.bat  (только после проверки FIELD E-STOP)
OPEN_SERVICE_CONSOLE.bat
```

Начинать с `START_HERE_RU.txt`, затем `FIELD_TEST_STEP9I_RU.md`.

## Безопасность

- Верхний `ПЛАВНЫЙ STOP ВСЕХ` = `2000H=0006` для всех четырёх HE200. Кнопка `Плавный STOP` внутри Assisted motion тормозит только активную пару.
- `0005 free/coast stop` намеренно не экспонируется.
- E-STOP должен быть независимым аппаратным средством и не заменяется браузером/USB/Arduino.
- Если браузер/USB завис — аппаратный E-STOP остаётся последним независимым уровнем.
- FIELD SERVICE предназначен только для пусконаладки; физический AUTO/HOME запрещён на уровне сборки.
