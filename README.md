# Telfer Control System (Arduino Mega 2560)

Этот проект — компактная «основа» управления двумя тельферами (2×горизонталь, 2×вертикаль) с автоматическим циклом «зоны → погружение → зоны…», ручным режимом, хранением программ в EEPROM и UI на графическом LCD.

## 1) Оборудование

- **Arduino Mega 2560** (PlatformIO + Arduino framework)
- **Дисплей GMG12864-06D**, контроллер **ST7565R**, интерфейс **SPI**, нужен **шрифт с кириллицей**
- **Лазерные дальномеры** 3.3V UART 9600 (2 шт) — горизонтальная позиция каждого тельфера
- **HC-SR04** 5V (2 шт) — высота/уровень груза (по одному под каждым тельфером)
- **Частотные преобразователи** NE/HE200 (4 шт) — 2 по горизонтали + 2 по вертикали, **RS485 Modbus RTU**
- **MAX485** (или аналог) для RS485
- **Энкодер** для меню + кнопка
- **Кнопки ручного управления**:
  - H1 вправо/влево, H2 вправо/влево
  - V1 вверх/вниз, V2 вверх/вниз (важно для наклона)
  - резерв: «оба тельфера горизонталь вместе»
  - START/STOP
- **E‑STOP** (желательно NC)
- **Концевики горизонтали** (4 шт, **NC**)
- Питание 3.3V для дисплея/лазеров (через стабилизатор), 5V для Mega/HC‑SR04

## 2) Важные направления (по уточнению)

- **H Forward = вправо**
- **V Forward = вниз**

В коде это базовое правило:

- +скорость на горизонтали = вправо
- +скорость на вертикали = вниз

## 3) Подключение (пины Mega)

Все пины можно менять в `include/config.h`.

### 3.1 Дисплей (SPI)

- SCK = 52
- MOSI = 51
- CS = 10
- DC = 8
- RST = 9
- Питание **3.3V**

### 3.2 RS485 (Modbus)

- Serial1: TX1=18, RX1=19
- DE/RE (управление направлением MAX485) = 6
- Скорость: 9600
- Формат: 8E1 (even parity) по умолчанию (см. Fd.03)

> Адреса частотников задаются в `include/motors.h` (по умолчанию 1..4).
> Если в ПЧ выставлена **без чётности (Fd.03=2)** — поменять в `src/app.cpp` `SERIAL_8E1` на `SERIAL_8N1`.

### 3.3 Лазеры (UART, 3.3V)

- Laser1 = Serial2 (TX2=16, RX2=17)
- Laser2 = Serial3 (TX3=14, RX3=15)

⚠️ **Mega (5V) → RX лазера (3.3V)** через понижение уровня (делитель/level shifter).

### 3.4 HC-SR04 (5V)

- US1 TRIG=22, ECHO=23
- US2 TRIG=24, ECHO=25

### 3.5 Кнопки и энкодер

- Энкодер: CLK=3, DT=4, SW=5 (INPUT_PULLUP)
- START=27, STOP=26
- «Оба вместе» H: FWD=28, BWD=29
- H1: FWD=40, BWD=41
- H2: FWD=42, BWD=43
- V1: UP=30, DOWN=31
- V2: UP=44, DOWN=45

### 3.6 Safety

- E‑STOP = 2 (рекомендуется NC + INPUT_PULLUP)
- Концевики (NC):
  - H1 LEFT=36, H1 RIGHT=37
  - H2 LEFT=38, H2 RIGHT=39

## 4) Программы и зоны

- Максимум зон: **10**
- Программа хранит:
  - X‑позицию тельфера 1 и 2 (мм) для каждой зоны
  - целевую высоту/уровень по УЗ (мм) для каждой зоны
  - время выдержки в жидкости (сек)
  - величину наклонного шага (мм)
  - паузу после наклона (сек)
- Порядок обхода зон настраивается (меню «ПРОГРАММЫ» → «Порядок»)
- Хранение в EEPROM: **4 слота** (выбор слота, загрузка, сохранение, копирование)

## 5) Автоматический алгоритм

Для каждой зоны по порядку:

1. Поднять оба тельфера на **travel‑высоту** (по УЗ) — безопасно для горизонтали
2. Доехать по горизонтали до целевых X (по лазерам)
3. Погружение в 2 этапа:
   - **Этап 1:** опускаем только «низкую» сторону (см. `LOW_SIDE_TELFER_INDEX`) на `tilt_step_mm`
   - **Пауза:** `step_wait_s` (дать трубам/полостям набраться жидкости)
   - **Этап 2:** опускаем оба тельфера до целевого уровня `us_target_mm`
4. Выдержка в жидкости: `dip_time_s`
5. Подъём в 2 этапа:
   - **Этап 1:** приподнимаем **высокую** сторону на `tilt_step_mm`
   - **Пауза:** `drip_wait_s` (дать жидкости стечь)
   - **Этап 2:** поднять оба на travel‑высоту
6. Следующая зона

После последней зоны — возврат «Домой».

## 6) Калибровка

Меню «КАЛИБРОВКА»:

- Выберите зону
- «Сохранить X» — запоминает текущие показания лазеров как X зоны
- «Сохранить высоту» — запоминает текущие показания HC‑SR04 как целевой уровень зоны
- «Dip time», «Tilt step», «Step wait» — настройка параметров
- «Сохранить HOME» — запоминает текущие X как домашние
- «Сохранить TRAVEL» — запоминает текущую высоту как travel‑высоту

После калибровки сохраните программу в слот (меню «ПРОГРАММЫ» → «Сохранить в слот»).
