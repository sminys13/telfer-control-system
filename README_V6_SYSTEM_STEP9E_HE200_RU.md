# V6 Step9E — HE200: безопасная проверка RS485 (READ-ONLY)

Эта версия сделана специально перед первым подключением реальных HE200.

## Почему отдельный Step9E

В старой версии проекта драйвер назывался NE200 и использовал старую карту записей 0x0001/0x0002.
В присланном руководстве HE200 эта карта записи RUN/STOP не подтверждена. Поэтому Step9E **никогда не пишет регистры HE200**: физический MAX485 включён, но разрешены только FC03-чтения мониторинга, прямо приведённые в HE200 User Manual.

Используются адреса:
- 0x7000 — текущая частота, 0.01 Hz
- 0x7001 — заданная частота, 0.01 Hz
- 0x7002 — напряжение DC-шины, 0.1 V
- 0x7003 — выходное напряжение, 1 V
- 0x7004 — выходной ток, 0.01 A при Pd.06=0
- 0x7007 — состояние цифровых входов X1..X4 (полезно для проверки физических кнопок)
- 0x702D — информация об ошибке
- 0x703B/0x703C/0x703D — текущая заданная/рабочая частота (%) и состояние привода

## Сборка

Для проверки четырёх лазеров без реального RS485 можно продолжать использовать:
`mega_v6_sensor_core_fast`

Для реального HE200 по MAX485 использовать **только**:
`mega_v6_he200_readonly`

В этой сборке любые команды движения/STOP по RS485 заблокированы на уровне прошивки.

## MAX485 ↔ Arduino Mega

- Mega TX1 pin 18 -> MAX485 DI
- Mega RX1 pin 19 <- MAX485 RO
- Mega pin 6 -> объединённые DE и /RE
- GND общий
- MAX485 A/B -> HE200 A+/A-

## Быстрый тест связи

После загрузки `mega_v6_he200_readonly` в терминале:

```text
he200 comm
test h1
test h2
test v1
test v2
```

`he200 comm` меняет параметры только в RAM на 9600 8-N-1, адреса 1/2/3/4. Ничего в EEPROM автоматически не сохраняется.

Нормальный ответ выглядит как `HE200 READ OK ...`. Если один ПЧ на столе, задайте ему адрес 1 и проверяйте `test h1`.

## Предварительные параметры самого HE200

Для общей сети четырёх ПЧ задайте каждому уникальный Pd.02: 1, 2, 3, 4.
На всех одинаково:
- Pd.00 = 5 -> 9600 bit/s
- Pd.01 = 3 -> 8-N-1
- Pd.03 = 2 ms можно оставить по умолчанию
- Pd.04 = 0.0 на первом тесте (контроль таймаута отключён)
- Pd.05 = 01 (стандартный Modbus)
- Pd.06 = 0, если хотим ток 0.01 A/единицу

## Физические кнопки и RS485

HE200 позволяет выбрать источник команды P0.02: 0 панель, 1 клеммы, 2 связь.
Для первичного теста физических кнопок используйте клеммный режим P0.02=1. Пример:
- P4.00 (X1) = 1 Forward RUN
- P4.01 (X2) = 2 Reverse RUN
- P4.11 = 0 (two-line mode 1)

Если нужен именно удерживаемый JOG, в руководстве есть функции X-входов 4 Forward JOG и 5 Reverse JOG; частота JOG задаётся P8.00.

В списке функций входов есть 20/37 `command source switchover`, то есть аппаратное переключение источника команда/связь предусмотрено. Но в присланной краткой инструкции нет однозначной таблицы логики состояния этих входов. Поэтому не используйте это как аварийную защиту и сначала проверяйте переключение без нагрузки.

Для будущего сетевого управления источник команды должен быть P0.02=2; источник частоты по связи — P0.03=9. Точный регистр записи RUN/STOP для HE200 мы сначала подтвердим и только после этого выпустим FIELD MANUAL прошивку.

## Двигатель

До движения заполните по шильдику двигателя P1.00..P1.05 (тип, мощность, напряжение, ток, частота, обороты). Не копируйте моторные числа от другого тельфера. Разгон/торможение P0.17/P0.18 на первом тесте оставьте существующими безопасными значениями.

## 4 лазера

Подключить X1/X2/Z1/Z2, затем перезагрузка или команда DWIN `0x0045 SENSOR REINIT`. В терминале должны быть четыре `fast init: OK` и четыре живых измерения.
