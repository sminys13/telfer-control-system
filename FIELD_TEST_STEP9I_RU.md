# Полевое испытание Step9I — пошагово

## До загрузки FIELD SERVICE

1. Убедиться, что четыре HE200 остаются механически безопасны для короткого движения.
2. Проверить аппаратный E-STOP и его NC-вход Mega. Без него FIELD SERVICE не использовать.
3. Освободить рабочую зону.
4. Закрыть PlatformIO Monitor перед Web Serial.
5. Собрать все среды `BUILD_STEP9I.bat` и получить `ALL STEP9I BUILDS: SUCCESS`.

## Этап A — общая готовность

Загрузить `mega_v6_he200_field_service`, открыть Service Cockpit и нажать **Подготовить систему**.

Приложение отправит профиль 9600 8N1, SEN0366 5 Гц/1 мм/10 м, опросит четыре ПЧ и запустит preflight.

Продолжать только если:

```text
PRE-FLIGHT = PASS
```

Если FAIL — не переходить к следующей стадии. Сохранить журнал. Ориентируйтесь на крупный баннер **СЛЕДУЮЩЕЕ ДЕЙСТВИЕ / GO-NO-GO** под воротами: он должен явно разрешить следующий этап.

## Этап B — доказательство протокола

ПЧ всё ещё должны находиться в STOP. Желательно на этом этапе оставить `P0.02=1`, чтобы control word не являлся активным источником движения.

Нажать **Проверить все 4**.

Продолжать только при:

```text
Протокол HE200 = 4/4
```

В журнале для каждого H1/H2/V1/V2 должны быть PASS и совпадение пробного 500 с `701C=500`.

## Этап C — переход на communication source

На каждом HE200 вручную:

```text
P0.02 = 2   Communication control
P0.03 = 9   Communication setting
```

После проверки четырёх ПЧ поставить соответствующую галочку в Service Cockpit.

Важно: штатные RUN/REV клеммы после P0.02=2 больше не являются источником команд движения. Аппаратный E-STOP остаётся обязательным.

## Этап D — четыре ПЧ по отдельности

Для H1:
1. Нажать `Коротко +`.
2. ПЧ должен кратко запуститься на 10% (при P0.10=50 Гц это ~5 Гц), затем сам получить deceleration stop.
3. Если браузер показал электрический PASS и физическое направление правильное — нажать `✓ + направление верно`.
4. Повторить `−`.

Так же H2, V1, V2.

Любой неожиданный эффект -> аппаратный E-STOP, испытание прекратить.

Переходить дальше только при:

```text
Направления = 8/8
```

## Этап E — пары

Коротко проверить H1+H2 вправо/влево, затем V1+V2 вверх/вниз.

Переходить дальше только при:

```text
Парные тесты = 2/2
```

## Этап F — проверка замедления по лазерам

### Горизонталь

Выбрать `X / H1+H2`, base speed сначала 20…40%.

Пуск + или −.

Ожидание:
- при нормальных данных плавный выход на basePct;
- age одного X >650 мс -> оба H замедляются;
- данные вернулись -> после свежих кадров оба снова разгоняются;
- age >1200 мс -> выбранная пара дотормаживает до 0;
- после 5 свежих кадров возможен мягкий рестарт;
- >5 с -> FAULT, выбранная пара получает плавный STOP; автоматического продолжения нет до `Сброс FAULT`.

### Вертикаль

То же для Z / V1+V2. Качание корзины не считаем ошибкой интерфейса; на этом шаге supervisor реагирует именно на возраст данных, не на сам скачок координаты.

## Этап G — программа

После успешной пусконаладки можно через вкладку «Программа» загрузить один тестовый слот и заполнить HOME/TRAVEL/1–2 зоны. Это не запускает физический AUTO.

Сохранить полный лог Step9I после испытаний.


### Различие двух STOP в браузере

- Верхняя красная `ПЛАВНЫЙ STOP ВСЕХ` — плавно останавливает H1/H2/V1/V2.
- `Плавный STOP` в блоке Assisted motion — останавливает только активную пару X или Z.
- Ни одна из них не заменяет аппаратный E-STOP.
