# Подключение оборудования — V6 Step9I

Этот документ относится к актуальной конфигурации:

- Arduino Mega 2560;
- DWIN по Serial2;
- два SC16IS752 по SPI;
- четыре UART-лазера X1/X2/Z1/Z2;
- четыре HE200 по изолированному Waveshare TTL TO RS485 (B);
- физические кнопки управления тельферами остаются подключены непосредственно к HE200.

## 1. Waveshare TTL TO RS485 (B)

### TTL-сторона

```text
Mega 5V       -> VCC
Mega GND      -> GND
Mega TX1 D18  -> RXD
Mega RX1 D19  <- TXD
```

Передача и приём подключаются крест-накрест.

### RS485-сторона

```text
Waveshare A+  -> HE200 A+
Waveshare B-  -> HE200 A-
```

Для первого короткого подключения:

```text
120R = OFF
SGND = не подключать
Mega D6 = не подключать
```

Модуль автоматически переключает направление. Соединение `DE/RE`, применявшееся со старым MAX485, отсутствует.

TTL GND соединяется с Mega GND. Изолированную сторону RS485 не замыкать обратно на Mega GND через SGND без отдельного обоснования — иначе теряется преимущество гальванической развязки.

## 2. Общая шина HE200

```text
Waveshare
   A+ / B-
      |
      +---- H1, Pd.02=1
      +---- H2, Pd.02=2
      +---- V1, Pd.02=3
      +---- V2, Pd.02=4
```

Шина должна быть последовательной. Избегать звезды и длинных ответвлений. Не прокладывать RS485 вплотную и параллельно моторным U/V/W.

Параметры:

```text
Pd.00 = 0005     9600
Pd.01 = 3        8-N-1
Pd.03 = 2 ms
Pd.04 = 0.0
Pd.05 = 01
Pd.06 = 0
```

До Protocol PASS оставлять существующий источник управления без изменения. После подтверждения нативной карты и непосредственно перед импульсными тестами FIELD SERVICE вручную установить на каждом HE200:

```text
P0.02 = 2   Communication control
P0.03 = 9   Communication setting
```

После P0.02=2 клеммные FWD/REV перестают быть источником рабочих команд. Аппаратный E-STOP должен оставаться независимым и доступным.

## 3. DWIN

```text
Mega TX2 D16 -> DWIN RX
Mega RX2 D17 <- DWIN TX
GND          -> GND
```

Скорость определяется `DWIN_BAUD` в текущей конфигурации V6.

## 4. SC16IS752

Оба SC16 работают на общей SPI-шине и имеют отдельные CS:

```text
Mega SCK  D52 -> SCK обоих SC16
Mega MOSI D51 -> MOSI/SI обоих SC16
Mega MISO D50 <- MISO/SO обоих SC16
Mega GND      -> GND
```

CS и частота кварца заданы в `include/config_v6_bringup.h`. Карта каналов:

```text
SC16 #1 channel A -> X1
SC16 #1 channel B -> X2
SC16 #2 channel A -> Z1
SC16 #2 channel B -> Z2
```

Эту карту перед тестом Step9I не менять.

## 5. Лазеры

Каждый лазер подключён к своему UART-каналу SC16:

```text
SC16 TX -> RX лазера
SC16 RX <- TX лазера
GND     -> GND лазера
питание -> по фактическим требованиям модуля
```

UART датчика:

```text
9600 8-N-1
```

Рабочий предел программной валидации:

```text
0 < distance <= 10000 мм
```

Рабочий профиль Step9I зафиксирован: continuous, код FRQ=5, выходное разрешение 1 мм, диапазон 10 м. Режимы 0,1 мм, FRQ=10/20 и alternating single-shot сохранены только как сервисные эксперименты.

## 6. Safety-входы Mega

```text
E-STOP       D2
H1 LEFT      D36
H1 RIGHT     D37
H2 LEFT      D38
H2 RIGHT     D39
```

В BENCH-сборке используется удобная active-low логика. В `mega_v6_he200_field_service` применяется FIELD/NC логика: исправная NC цепь удерживает вход LOW, разрыв/срабатывание даёт HIGH и блокирует допуск. Программный вход Mega и логический STOP HE200 не заменяют независимую аппаратную аварийную цепь.

## 7. Что удалено из актуальной схемы

Следующее относится к legacy и не должно использоваться как инструкция Step9I:

- графический GMG12864;
- матричная клавиатура 4×4;
- HC-SR04;
- два прямых UART Mega для лазеров;
- MAX485 с DE/RE на D6.

## 8. Контрольная мишень лазеров

Для диагностики SEN0366 использовать жёсткую плоскую матовую светло-серую или белую мишень достаточного размера. Подтверждённый на объекте вариант — жёсткая металлическая пластина с матовой светло-серой поверхностью. Крепление к корпусу двигателя допустимо, если пластина жёстко связана с механизмом, не прогибается и точка остаётся вдали от краёв. Не направлять луч на глянец, зеркало, стекло, мокрую или крупно-рельефную поверхность как на базовый эталон.

При 10 м заявленный диаметр пятна около 6 мм. Положение точки должно оставаться вдали от краёв, крепежа и швов.
