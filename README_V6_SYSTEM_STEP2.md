# V6 System Step 2

Эта версия возвращает системную логику режимов поверх рабочего датчикового ядра.

## Что оставлено как рабочая база

- Лазеры: `RANGE 10m -> RESOLUTION 1mm -> FREQ 20Hz -> CONTINUOUS`.
- Без `SINGLE`, без `READ_CACHE`, без автоматического рестарта.
- Координаты `X1/X2/Z1/Z2` не сбрасываются в 0 при потере свежих кадров.
- `ZERO/SAVE/LOAD/RESET CAL` работают через EEPROM.

## Команды DWIN

Все кнопки пишут в `VP_CMD = 0x1100` как `Return Key Code`, `Data auto-uploading = ON`.

Основные:

- `0001` — Ручное управление
- `0002` — Авто
- `0003` — Домой
- `0004` — Стоп
- `0005` — Настройки
- `0006` — Калибровка

Калибровка:

- `0021` — ZERO X1
- `0022` — ZERO X2
- `0023` — ZERO Z1
- `0024` — ZERO Z2
- `0030` — SAVE
- `0031` — LOAD
- `0032` — RESET CAL

Сервис:

- `0044` — CLEAR STATUS
- `0045` — SENSOR REINIT

Навигационные кнопки вроде «Назад», если не должны выполнять команду Arduino, ставить `key value = 0000` или отключать `Data auto-uploading`.

## VP_MODE

Arduino пишет текущий режим в `VP_MODE = 0x1010`:

- `0` — Service / boot
- `1` — Manual
- `2` — Auto
- `3` — Home
- `4` — Stop
- `5` — Settings
- `6` — Calibration

## MotorControlV6

Добавлен безопасный слой `MotorControlV6`. Он пока не управляет реле и не отправляет команды частотникам. Он только логирует переходы режимов и принудительно выполняет `stopAll()` при `STOP`.

Реальные RS485/VFD-команды будем добавлять внутрь `motor_control_v6.cpp` следующим этапом.
