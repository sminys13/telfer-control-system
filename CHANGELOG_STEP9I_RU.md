# Step9I — изменения относительно Step9H

- добавлена подтверждённая нативная карта HE200 `1000H/2000H/3000H`;
- добавлена отдельная FIELD SERVICE сборка с runtime gates;
- free/coast stop `0005` исключён из доступных сервисных команд;
- штатный stop HE200 = `0006` deceleration stop;
- добавлен безопасный protocol probe на стоящем ПЧ;
- добавлены низкоскоростные импульсные тесты и операторское подтверждение направления;
- добавлены парные H/Z тесты;
- реализовано совместное замедление пары при устаревании любого датчика;
- реализовано восстановление скорости после 3 свежих парных кадров и рестарт после остановки после 5;
- браузерная консоль переработана в Service Cockpit;
- удалены из основного UI ненужные эксперименты 10/20 Гц, 0.1 мм, single-shot;
- добавлен резервный редактор EEPROM-программ;
- физические AUTO/HOME остаются заблокированы;
- DWIN-команды движения отключены в FIELD SERVICE;
- CI переведён на три реально поддерживаемых среды Step9I.

- добавлен единый GO/NO-GO баннер следующего действия в Service Cockpit;
- уточнена область торможения: sensor-assist и его STOP действуют только на активную пару, глобальный STOP — на все четыре HE200;
