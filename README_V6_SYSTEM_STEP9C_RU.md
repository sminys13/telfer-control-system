# V6 SYSTEM STEP9C — русская справка по DWIN

Версия прошивки: **v6-system-step9c**.

Эта памятка описывает именно текущую V6/Step9C для сенсорного DWIN. Старый `docs/menu_guide_ru.md` относится к прежнему строчному экрану/клавиатуре и не должен использоваться как карта нового HMI.

---

## 1. Главное правило: навигация и команды — разные вещи

В DWIN есть два типа действий:

1. **Переход на страницу** — выполняется самим дисплеем (Page Switching). Для Arduino код не нужен.
2. **Команда Arduino** — кнопка типа Return Key Code пишет значение в **VP 0x1100**.

Для команд:
- VP: **0x1100**
- Key value: код из таблиц ниже
- Data auto-uploading: **ON**

### Критически важно

- Кнопка **«Главная»** = только переход на главный экран DWIN. Она **НЕ** должна отправлять `0x0003`.
- `0x0003 HOME / Домой` = запуск физического алгоритма возврата механизма в HOME.
- Нижняя кнопка **«Авто»** должна открывать страницу AUTO. Сам запуск программы выполняется отдельной кнопкой **«СТАРТ» = 0x0002**.
- **«Программы»**, **«Редактор 1»**, **«Редактор 2»**, **«Координаты»**, **«Вернуться»** — это переходы между страницами DWIN; отдельные команды Arduino для них в Step9C не нужны.

---

## 2. Рекомендуемое нижнее меню

| Кнопка | Что делать |
|---|---|
| Главная | Page Switch на главный экран; без команды Arduino |
| Ручной | Page Switch + `0x0001` для входа в MANUAL |
| Авто | Page Switch на экран AUTO; **не запускать AUTO здесь** |
| Программы | Page Switch на экран программ; без команды Arduino |
| Калибровка | Page Switch + `0x0006` |
| Настройки | Page Switch + `0x0005` |
| СТОП | `0x0004` — глобальный STOP |

Если конкретный объект DGUS не умеет одновременно Page Switch и Return Key Code, переход страницы можно оставить отдельно, а команду режима назначить отдельной невидимой/служебной кнопке или позже перевести переход страниц под управление Arduino.

## 3. Основные команды

Все пишутся в VP `0x1100`.

| Функция | Код |
|---|---:|
| MANUAL | `0x0001` |
| AUTO START | `0x0002` |
| HOME (физический возврат механизма) | `0x0003` |
| Глобальный STOP | `0x0004` |
| SETTINGS | `0x0005` |
| CALIBRATION | `0x0006` |

## 4. Сервисные кнопки

| Функция | Код |
|---|---:|
| Сброс статуса | `0x0044` |
| Реинициализация датчиков | `0x0045` |
| Диагностический снимок | `0x0046` |
| Сброс защёлки E-STOP | `0x0047` |
| Вкл/выкл контроль E-STOP | `0x0048` — только BENCH |

## 5. Ручное управление

| Действие | Код |
|---|---:|
| H1 вправо / POS | `0x0101` |
| H1 влево / NEG | `0x0102` |
| H2 вправо / POS | `0x0103` |
| H2 влево / NEG | `0x0104` |
| H1+H2 вправо | `0x0105` |
| H1+H2 влево | `0x0106` |
| V1 вверх | `0x0107` |
| V1 вниз | `0x0108` |
| V2 вверх | `0x0109` |
| V2 вниз | `0x010A` |
| V1+V2 вверх | `0x010B` |
| V1+V2 вниз | `0x010C` |
| STOP ручного движения (JOG STOP) | `0x010F` |

### Нужно ли оставлять отдельную кнопку `0x010F`?

Пока **да, лучше оставить**. Это не то же самое, что красный глобальный STOP:

- `0x010F` останавливает текущее ручное движение, но оставляет систему в MANUAL;
- `0x0004` переводит всю систему в STOP и останавливает всё.

Когда настроим надёжное «нажал стрелку → движение, отпустил → 0x010F», отдельную кнопку JOG STOP можно будет убрать. До этого она полезна как дополнительная страховка.

Нижняя навигационная кнопка «Авто» должна только открыть экран AUTO. Код `0x0002` назначается кнопке **СТАРТ** внутри страницы.

## 7. Программы — кнопки

### Выбор/загрузка слота

| Кнопка | Код |
|---|---:|
| Программа 1 | `0x0314` |
| Программа 2 | `0x0315` |
| Программа 3 | `0x0316` |
| Программа 4 | `0x0317` |
| Загрузить текущий слот | `0x0310` |
| Сохранить текущий слот | `0x0311` |
| Безопасные значения по умолчанию | `0x0312` |

**В Step9C кнопки `0x0314..0x0317` не просто выделяют карточку — они сразу загружают выбранный слот.** Поэтому перед переходом на другой слот сначала сохраняйте изменения, иначе несохранённые данные текущего слота будут потеряны. В следующей версии лучше разделить SELECT и LOAD.

### Выбранная зона

| Кнопка | Код |
|---|---:|
| Предыдущая зона | `0x0318` |
| Следующая зона | `0x0319` |
| Зона ВКЛ/ВЫКЛ | `0x031A` |

### Снять координаты с реальных датчиков

| Функция | Код |
|---|---:|
| Снять HOME X1/X2 | `0x0320` |
| Снять TRAVEL Z1/Z2 | `0x0321` |
| Снять X1/X2 выбранной зоны | `0x0322` |
| Снять Z1/Z2 выбранной зоны | `0x0323` |
| Снять Dry X1/X2 | `0x0324` |
| Снять Dry Z1/Z2 | `0x0325` |

### Подтвердить вручную введённую пару

| Функция | Код |
|---|---:|
| Принять X1/X2 зоны | `0x0326` |
| Принять Z1/Z2 зоны | `0x0327` |
| Принять HOME X1/X2 | `0x0328` |
| Принять TRAVEL Z1/Z2 | `0x0329` |
| Принять Dry X1/X2 | `0x032A` |
| Принять Dry Z1/Z2 | `0x032B` |

Важно: ввод только X1 или только X2 не делает пару валидной. Для ручного ввода нужно ввести обе координаты пары, затем нажать соответствующее «Принять».

| Сушка ВКЛ/ВЫКЛ | `0x1330` |
| Время сушки, с | `0x1332` |

| Скорость наклона, % | `0x1346` |
| Выбранный слот программы | `0x1348` |
| Состояние редактора | `0x134A` |
| Редактор заблокирован AUTO/HOME | `0x134C` |

### Важно про «угол слива»

В текущей Step9C **угол в градусах не задаётся**. Поле `0x1310` — это разница/ход одной вертикальной стороны в **миллиметрах** (`tiltStepMm`). Поэтому на текущей картинке правильнее подписать поле:

**«Шаг наклона, мм»** или **«Перепад при сливе, мм»**,

а не `30°`.

Если позже захотим задавать именно угол в градусах, нужно знать геометрическое расстояние между точками подвеса и добавить пересчёт `угол → перепад высоты`.

### Формат чисел

Step9C хранит редактируемые значения как целые числа: мм, секунды и проценты. Для первых полевых тестов лучше не использовать десятичный ввод `10.0`/`0.000` в редактируемых полях, пока отдельно не введём фиксированное масштабирование.

## 9. Калибровка

| Функция | Код |
|---|---:|
| ZERO X1 | `0x0021` |
| ZERO X2 | `0x0022` |
| ZERO Z1 | `0x0023` |
| ZERO Z2 | `0x0024` |
| Сохранить настройки/калибровку | `0x0030` |
| Загрузить настройки | `0x0031` |
| Сбросить калибровку целиком в RAM | `0x0032` |

В Step9C **нет отдельного кода «СБРОС X1», «СБРОС X2», «СБРОС Z1», «СБРОС Z2»**. На картинке эти четыре кнопки пока лучше не активировать. Рабочая кнопка «Сбросить все» = `0x0032`.

## 12. Что реально нужно настроить на экранах прямо сейчас

Минимальный набор для продолжения работ:

1. Нижнее меню: Главная, Ручной, Авто, Программы, Калибровка, Настройки, STOP.
2. На MANUAL: 12 команд движения + `0x010F`.
3. На AUTO: START `0x0002`, PAUSE `0x0300`, RESUME `0x0301`, NEXT `0x0302`, STOP `0x0004`, HOME `0x0003`.
4. На PROGRAMS: P1..P4 `0x0314..0x0317`, Load `0x0310`, Save `0x0311`, Defaults `0x0312`.
5. Editor 1: Prev/Next zone `0x0318/0x0319`, Zone ON/OFF `0x031A`, Capture X/Z `0x0322/0x0323`, Accept X/Z `0x0326/0x0327`, числовые VP `0x1300..`.
6. Editor 2: времена/скорости/наклон/сушка через VP `0x130E..0x1346`.
7. Calibration: ZERO `0x0021..0x0024`, Save `0x0030`, Load `0x0031`, Reset all `0x0032`.
8. Service: Clear status `0x0044`, Sensor reinit `0x0045`.
9. RS485: `0x0200..0x0208` + VP `0x1200..`.

Остальную декоративную/расширенную функциональность экранов можно спокойно подключать позже.
