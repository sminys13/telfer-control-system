# v6 continuous 20Hz experiment

Экспериментальная версия для проверки линии до 10 м.

Изменения в fast continuous-драйвере:

1. При старте каждого датчика отправляется последовательность:
   - `80 06 05 01 74` — Laser ON
   - `04 09 0A EF` — диапазон 10 м
   - `04 0C 01 F5` — разрешение 1 мм
   - `04 0A 14 E4` — частота 20 Гц
   - `80 06 03 77` — continuous mode

2. Одиночные измерения `80 06 02 78` не используются.

3. `READ_CACHE` постоянно не дергается. Контроллер только читает поток, который датчик отдаёт сам в continuous.

4. Последнее валидное значение остаётся на DWIN, при потере обновления меняется только `ERROR`.

Если станет хуже, в `include/config_v6_bringup.h` можно быстро отключить настройки:

```cpp
FAST_LASER_SET_RANGE_10M = false;
FAST_LASER_SET_RESOLUTION_1MM = false;
FAST_LASER_SET_FREQ_20HZ = false;
```
